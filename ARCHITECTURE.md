# LSS | System Shape and Trust Boundaries

Status: stable architectural intent, **not** a claim that every component below is deployed.

## Two clocks
The first clock makes the best presently supportable standalone wanted asset from one Source. The second clock uses later evidence, releases, reappearances or models to improve that same Asset. Neither waits for the other.

```
user Source + wanted semantic intent
      -> inspect / detect occurrence(s) / candidate regions
      -> autonomous plan (RAW, separator, cleanup, donors, local repair)
      -> preserve a portfolio of useful candidate/region/component views
      -> semantic + quality decision (including UNKNOWN/HELD)
      -> stable Asset/Revision and representation class
      -> CurrentBest selection -> listening derivative -> library / COMPLETE
                                  ^
      memory + later Reference/Occurrence/Recipe Evidence -----|
```

## Trust boundaries
**Source evidence:** immutable source identity and timeline; derived outputs never overwrite the explanation of what was heard.
**Semantic judgment:** user intent and music role are distinct from audio-model stem taxonomy, program boundary, track metadata and retrieval scores.
**Audio construction:** a valid whole-cue winner may be assembled from local regions/components but each donor must have justified coverage, timing and continuity.
**Product decision:** Evidence may support HOLD, reuse, promotion, regeneration or invalidation; it may not silently erase CurrentBest.
**Persistence:** history and provenance survive physical cache eviction when reproducible; user media remains user-owned.
**User projection:** tags, visible names and READY/PROCESSING/COMPLETE reflect actual Product state, not another source of truth.

## The capability graph
Model/checkpoint/provider is an implementation of capabilities, not a Product target. Recipes may be conditional, parallel, region-specific or recursive, including original mixture/no-op, multi-stem, wrong-stem rescue, dialogue/SFX cleanup, occurrence/reference donor, recombination, local reconstruction, enhancement and abstention.

## Completion and attack surface
Reduce Product distance through end-to-end journeys, not completed abstractions. A severe SFX frontier is not a prerequisite for useful results in less difficult regions; a missing released reference is not a prerequisite for single-episode extraction. Do not make a giant new database or evaluator framework just because it might someday help.
